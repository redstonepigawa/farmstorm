以下为追加的内容
1.农产品转换器重做
{
	方块名：农作物转换器
	方块硬度和爆炸抗性参考铁砧
	带有标签：farmstorm:processing_block（实装 ID：冒号分隔）
	功能：当且仅当该方块处在一个己方据点核心影响范围内并且被一个己方据点核心绑定时可使用，手持有对应改良农作物的原版农作物或平凡农作物右键可将其放入该方块中转换，一次只能放入一个，三十秒后产出1个对应改良农作物并自动存放在其绑定的据点核心的存储空间中，当其处于工作状态时播放预设好的翻书动画，与据点核心的连线为红色（与农作物培养器和据点核心之间的**青色**连线相对应；实装：转换器 `0.92/0.22/0.22`、培养器 `0.30/0.85/0.90`）
	材质："C:\Users\DASHpig\Downloads\crop_converter_a_32x32_pack"
	合成配方：铁锭 铁锭 铁锭
			玻璃	红石粉 玻璃
			铁锭 铁锭 铁锭
	（实装：即 **6 铁锭 + 2 玻璃 + 1 红石粉** → 1 个 `farmstorm:crop_converter`，配方 id 也随方块改名）
}
2.改良农作物不再拥有种子
{
	移除所有改良农作物的种子，若该改良农作物有对应的平凡作物，则将该种子转为对应平凡作物的种子
	（实装：7 个改良作物种子**全部删除**；实际动作是把 `chive_seeds.png` 重命名为 `plain_chives_seeds.png` 并**新增** `plain_chives_seeds` 物品——v0.2.2 的平凡韭菜当时还没有种子。`#farmstorm:seeds` 标签成员 6 → 1）
}
3.农作物培养器修改
{
	农作物培养器只能培养原版农作物和平凡农作物，不再能培养改良农作物，史诗品质的改良农作物对应的原版农作物或平凡农作物不能被培养
	增加合成配方： 铁锭 玻璃 铁锭
			 	玻璃	红石粉 玻璃
				铁锭 玻璃 铁锭
	（实装：即 **4 铁锭 + 4 玻璃 + 1 红石粉** → 1 个 `farmstorm:cultivator`，`unlockedBy` 用原版玻璃）
}

	man瓜的炮弹在飞行300刻后会被直接删除
}
