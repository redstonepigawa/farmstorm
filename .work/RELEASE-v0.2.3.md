# Farmstorm 农场风云 v0.2.3

> Minecraft **1.21.1** · NeoForge **21.1.x** · Java **21** · modid `farmstorm`

这一版把**农业流水线闭环**了：种原版 → 培养器增殖 → 转换器升级。五条需求 + 一条附带：**农作物转换器重做**、**改良作物不再有种子**、**培养器只收原版与平凡作物**、**平凡韭菜可种植**、**man瓜炮弹 300 刻寿命**、**进度文案改字**。

注册面 **98 → 92**（删 7 个种子、加 1 个种子、加 1 个方块、删 1 个菜单；转换器改名不计数），server config **176 → 175 键**，语言键 **340 → 321 × 2**，网络包仍 **2 个**（协议串 **2 → 3**），红线仍**无 Mixin**。

## 本版改了什么

**R1 · 农作物转换器（`farmstorm:crop_converter`，取代旧的 `farmstorm:converter`）**
- 硬度与爆炸抗性**照铁砧**（5.0 / 1200）、要镐才掉、活塞推不动。
- 右键把手上**一个**原版农作物或平凡农作物放进去；**30 秒（600 刻，可配）**后产出 **1 个**对应改良作物，并**自动送进绑定的据点核心**。
- **没有界面**、不收经验、不收下界之星；工作时方块播**翻书动画**，与核心的连线变**红色**（培养器那条仍是青色）。
- 合成：**6 铁锭 + 2 玻璃 + 1 红石粉**。

**R2 · 改良作物不再有种子**
- 7 个种子物品**全部删除**；改良作物从此只能靠**转换器产出**、**植物学家交易**或**创造栏**获得，不能再种。
- 15 个改良作物方块仍然注册，但正常玩法拿不到（与上一版一致）。

**R3 · 农作物培养器：准入判据反过来**
- 现在**只收原版农作物与平凡作物**，一个改良作物也收不进去；史诗档对应的原版物品（火把花 / 瓶子草荚 / 甜浆果 / 金苹果）不能培养 —— 可培养的投入物共 **17** 个。
- 每次给 **2 个投入物 + 2 个对应种子**；「自身即种子」的（胡萝卜 / 马铃薯 / 毒马铃薯 / 仙人掌 / 竹子 / 蘑菇 / 可可豆 / 甘蔗 / 菌）直接给 **4 个同一物品**。
- 第一次有了合成配方：**4 铁锭 + 4 玻璃 + 1 红石粉**。

**R4 · man瓜炮弹 300 刻寿命**
- `TurretBullet` 出膛后第 **300 刻（15 秒，可配）**静默消失。只作用于 man瓜（`pumpkin_turret`）的炮弹，`瓜！` 那条线一行未动。

**R5 · 进度文案**
- 「最扎人的一集」的描述从「触发一次「赢过输过没死过」」改为「触发一次「**刺球**」」，中英同步。

**附带（作者裁定）· 平凡韭菜变成能种的作物**
- 新增 `plain_chives_crop` 方块与 `plain_chives_seeds` 种子（贴图复用朋友的韭）；它也是唯一能靠转换器变成朋友的韭的平凡作物。
- 平凡作物**不进** 22 条作物档案，因此不影响幸运浆果池与改良作物标签。

| 项 | 会发生什么 | 怎么办 |
|---|---|---|
| **老存档有损**（既定代价，不是 bug） | 已放置的 `farmstorm:converter` 方块变成**缺失方块**；背包里那个物品失效；7 种改良作物种子物品失效 | 这是「方块改名 + 删种子」两条裁定的代价，无迁移工具 |
| 已完成「装个转换器」进度 | **不丢**（进度 id 仍是 `farmstorm:converter`），但不再与新方块联动 | 无需操作 |

| 语言键 340 → 321 | 删 23（7 种子 + 9 GUI + 3 config + 4 进度）、加 4、改名 2、改值 2 | 无需操作 |

| 物品 / 配方 / 进度 / 方块 id | 除上述改名与删除外全部不变 | 其余无需迁移 |

## 已知影响：史诗农作物变便宜了

- 转换器不再收**下界之星**、也不扣经验 ⇒ 火把花与瓶子草这两个史诗作物，从「要下界之星 + 扣经验、基本拿不到」变成「**30 秒产 1 个**」。
- 史诗档的另一个入口照旧：植物学家 5 级那一项，40-64 绿宝石、只能换一次。

## 平衡变更：培养器产出翻倍

- 准入判据反转后，「自身即种子」的那 **11 条**投入物每次给的数量**翻倍**：从 2 个变成 **4 个**。
- 有独立种子的那一档仍是「2 个投入物 + 2 个对应种子」，没有变化。
- 一句话记：**给得出种子的一档不变，给不出种子的一档翻倍。**

## 已知限制

- 连线线框与核心浮窗需要装本模组的客户端；纯原版客户端能进服，但看不到它们。
- 连线的青 / 红两色、浮窗观感、翻书动画**未经人眼验收**（验收环境没有渲染面）。
- 老存档里已超过 4 个据点核心不会被回收；拆掉核之后绑不回去的机器留原地、永久不可用，只能拆掉重放。
- 培养器与转换器**共享**同一个核心名额上限（默认 24）。
