# Farmstorm 农场风云 v0.2.1

> Minecraft **1.21.1** · NeoForge **21.1.x** · Java **21** · modid `farmstorm`

四条追加需求 + 一条数值调整：**核心自己收编培养器**、**核心储物 90 格显示详情**、**震动豆与 Q弹 让生物停手**、**陷阱对敌对生物 ×3**。
注册面仍是 **97（+0）**，网络包仍是 **2 个**，红线仍是 **无 Mixin**。

## 本版改了什么

**R1 · 据点核心自动收编培养器**
- 每 **100 刻**扫一次自己的 3×3 区块，把还没绑定的培养器补进「少于 16」的名额；满 16 就停。
- 补绑有**自己的相位门**，不复用边界粒子那道 —— 把 `boundaryParticleIntervalTicks` 拉到 1200，补绑仍然是 100 刻内补上（判决性验收 #6 + #7 成对跑）。
- 没有主人的核不收编；读不到的区块跳过，**不会为了补绑去加载区块**。
- 这是 v0.2.0「运行期不做定期重绑」的一次性例外；选核判据 / 16 上限 / 一对一 / 核侧唯一真相全部保留。

**R2 · 核心储物 90 格显示原版 tooltip**
- 54 格储物 + 玩家背包共 90 格，悬停即出物品名与详情行；数量为 1 时不显示「1」，空格子不弹框。
- 这是「保证原版链路没被绕过」的验收项 —— 界面代码**一行未改**（`OutpostCoreScreen` 仍只覆写 `renderBg`）。

**R3 / R4 · 震动豆与 Q弹 让生物停手**
- 震动豆：球内**所有**非玩家生物停手 **80 刻**（4 秒），不是只停触发那一只。
- Q弹：带效果的生物在效果存续期间一直停手；效果自然到期或中途清除，都在 1 刻内恢复。
- 恢复一律按**原值**写回：本来就 `noAi` 的怪不会因为踩了陷阱被放出来（`#14 + #15` 成对跑）。
- AI 原值落盘在实体上（**第 13 类附件** `farmstorm:ai_suspend`），用完即删；`/stop` 走提前恢复、崩溃走载入结算（`#23 + #24` 成对跑）。

**R5 · 陷阱对敌对生物 ×3**
- 新增 `trap.damageMultiplier`（默认 **3.0**，范围 1.0 ~ 10.0）。
- 只有 `blast_carrot` 与 `zangief_cane` 参与：对敌对生物 = `min(raw, 7) × 倍率` ⇒ 胡罗贝 **21.0** / 桑吉尔蔗 **22.5**（1.0 / 3.0 / 10.0 三档实测 7.0 / 21.0 / 70.0 与 7.5 / 22.5 / 75.0）。
- 玩家恒按原值（胡罗贝最高 **7.0**，三档读数相同）；中立 / 被动生物同样走原值；非陷阱爆炸在倍率 1.0 / 3.0 / 10.0 下**逐点相同**。
- 尖牙仙人掌走原版 `EvokerFangs` 不参与，震动豆本来就是 0 伤害。

## 已知限制

- **悬停 tooltip 的观感未经人眼验收**：本版验收跑在专用服务端 + 协议机器人上，没有渲染面；代码层证据是「界面没有覆写 `renderTooltip`、90 格全部交给原版 `Slot`」，实际显示效果需要玩家确认。
- 补绑是**每核心 100 刻一次**；满 16 的核不补，无主核不补；先放培养器后放核要等下一轮才被认领。
- `trap.damageMultiplier` **只作用于 2 个陷阱作物**；尖牙仙人掌与震动豆不受影响。
- 培养器必须在核的 3×3 区块内才可用；史诗作物只能靠农民交易；培养器没有槽位界面。
- 连线与浮窗需要装本模组的客户端；纯原版客户端仍能进服，只是看不到它们。连线的视觉观感同样未经人眼验收。
- 震动豆的「不触发」反向断言只对生存模式、非己方的玩家成立：创造 / 旁观不触发，但仍会被晕到（0.2.0 起的既存口径）。
- 历史遗留（0.0.2 起）：灰度只作用于世界（HUD 保持原色）、桑吉尔蔗相位 2 只是降速约 15.6 倍、F11 / F2 / F3 / ESC 拦不住、1×1 石柱落地约 23 刻、狂野猎人期间设置界面的亮度滑条显示为满、火把花光环离场后火焰附加最多再留 15 秒、干耕地会毁苗、据点核心边界粒子每圈 48 个包。
