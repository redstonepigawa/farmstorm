# Farmstorm 农场风云 v0.2.4

> Minecraft **1.21.1** · NeoForge **21.1.x** · Java **21** · modid `farmstorm`

四条需求 + 一项清理：**绑定统一（修一个静默 bug）**、**村民交易经验分级**、**核心浮窗底色变淡**、**放置方块音效修好**，外加**删掉 780 行耕地死代码**。

注册面仍 **92**、server config 仍 **175 键 / 60 组**、语言键仍 **321 × 2**、网络包仍 **2 个**（协议串仍 `"3"`）、红线仍**无 Mixin**；唯一变化的数字是 **Java 文件 152 → 151**（删 2 个死类 + 新增 1 个接口）。

## 本版改了什么

**R1 · 绑定统一（修 bug + 改成标签驱动）**
- **以前的 bug**：拆掉据点核心后，农作物转换器身上还留着死坐标，之后就算在 3×3 区块里放新核也**永远绑不上**，而且服务端不报错、不打日志。
- **现在**：拆核时转换器的 `Core` 键会被清掉（内部待转换物与进度**都保留**）；放进新核后一个补绑周期内自动重新绑定。
- 机制：候选发现改成「**凡带 `farmstorm:processing_block` 标签的方块都能被核绑定**」，两台机器走同一个三方法接口（读取 / 写入 / 清除绑定），连线类型由核侧一张「方块 → 连线类型」的单一映射给出。

**R2 · 村民交易经验分级**
- 1 ~ 5 级的成交经验从统一 2 点改成 **2 / 5 / 10 / 15 / 30** 点；植物学家与农民同一口径（26 条交易 listing 逐项携带自己的值）。
- **价格、次数、每次给几个都不变**；经验只影响村民升级的快慢。

**R3 · 核心浮窗底色变淡**
- 内层底板不透明度 **50% → 30.2%**（`0x4D000000`），边框与三种文字色不变。
- 硬编码在渲染类里，**不新增任何配置键**（客户端配置仍是 `hud.enabled` / `hud.x` / `hud.y` 三个）。

**R4 · 放置方块有声音了（客户端预测）**
- 以前放置据点核心 / 培养器 / 转换器时，**放置者本人听不到**落地音，旁边的人听得见。
- 现在三处右键的客户端分支改成「**手上拿的是这台机器认的输入物才接走，否则让路**」，放置音由服务端照常广播给所有人。
- 服务端那四道闸（范围 / 绑定 / 手持 / 空槽）**一行未改**。

**附带 · 死代码清理**
- 删掉 0.2.0 撤销「耕地-核心绑定」后遗留的两个类（`FarmlandGuard` / `FarmlandLedger`，共 **780 行**）与三处悬挂引用。**不影响任何玩法**：它们早就没有运行期调用者。

## 从 v0.2.3 升级必看

| 项 | 会发生什么 | 怎么办 |
|---|---|---|
| **存档无损** | 本版不改注册 id、不删物品、不加配置键、语言键不变、协议串仍是 `"3"` | 老存档直接进 |
| 配置不用删 | server config 仍 175 键 / 60 组；client config 仍 3 键 | 无需操作 |
| **右键「无反应」的新口径** | 客户端只看物品品类，服务端还看范围 / 绑定 / 手持 / 空槽 ⇒ 手上不是输入物、槽里已有货、或机器未绑定时右键就是没反应 | 这是**已知影响**，不是缺陷 |
| 手持方块右键自家核 | 客户端会先按「放置」预测一次，服务端仍在右键里打开 54 格储物界面 | 已知影响（预测与开界面之间的落差由原版收尾） |
| 老存档的 `farmstorm:converter` 与 7 种种子 | v0.2.3 已下线，本版不恢复 | 无需操作 |

## 已知影响

1. **客户端只看品类**：右键「无反应」不是坏了，服务端四闸仍在（见上表）。
2. **己方玩家手持方块右键核**会先走一次放置预测。
3. **新增标签成员必须同表登记连线类型**：否则该成员能被发现却拿不到 kind，会绑不上。
4. **交易经验按级而不是按档**：作物档位（普通 / 稀有 / 史诗）与交易等级不是同一根轴。

## 已知限制与未实测

- 连线线框与核心浮窗需要装本模组的客户端；纯原版客户端能进服但看不到。
- **未实测三项**（验收环境缺条件，按「未实测」记录而非「已验证」）：只有放置者听不见、副手放置、客户端配方表可用性。
- 浮窗底色的**像素取色**与放置音的**双客户端音频轨**两条未实测（无图形客户端 / 无第二台机器），替代读数是常量与计数。
- 老存档里已超过 4 个据点核心不会被回收；拆掉核之后绑不回去的机器留原地、永久不可用。
