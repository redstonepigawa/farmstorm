1.狂野猎人冲刺蓄力条优化
{
	将冲刺蓄力条稍微上移，防止被生命值条和饥饿值条挡住
}
2.朋友的韭材质增加
{
	增加处于种植状态的朋友的韭的材质
}
3.膨胀麦和压缩膨胀麦bug修复
{
	膨胀麦和压缩膨胀麦落地时生成的方块不再能替换掉普通方块，但仍可以替换液体方块和空气方块
	压缩膨胀麦的模型改为立体的干草块
}
4.瓜！与瓜片子调整
{
	移除二者的破障类词条，不再能炸毁方块
	瓜！爆炸后产生的瓜片子落点更加密集
}
5.农作物种植调整
{
	所有本模组农作物生长时间改为[20，45]秒
}
6.陷阱类作物调整
{
	当有玩家触发陷阱后获得五秒同类陷阱免疫，期间不会再次触发同类陷阱
	所有陷阱被部署后每隔五秒产生少量“dust”粒子
	陷阱可以被所有敌对生物触发
每个玩家最多同时部署16个陷阱，超过16个的新部署陷阱会使最先部署的陷阱消失（就是一个FIFO队列，最多只能存储16个元素，再多就需要将队首元素出队）
}
7.新增游戏规则
{
	限制玩家开垦耕地数量，默认为0，当多个玩家处于同一个队伍时，其耕地数量上限为队伍内所有玩家的耕地上限总和，玩家只有在处于己方据点核心所在区块或周围八个区块才可以耕地
	可使用/gamerule指令修改玩家可开垦耕地数量上线
	（实装：**这一段整体已撤销** —— v0.2.0 停用「耕地-核心绑定」，该 gamerule 已删除（当前 `GameRules.register` 命中 0），耕地不再受数量与位置限制）
}
