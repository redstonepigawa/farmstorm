# Farmstorm 农场风云 v0.1.1

> Minecraft 1.21.1 · NeoForge 21.1.213 · Java 21 · modid `farmstorm`
> 下载：`farmstorm-0.1.1+mc1.21.1.jar`（1,063,181 字节 / SHA256 `B20E2EA305AE2F1943756696C3DE7090965FD31D525ECC8F370B2F3CF746F2A5`）
> 源码包：`farmstorm-0.1.1+mc1.21.1-sources.jar`（978,402 字节 / SHA256 `0E9A03AC20945CB89C495C047B926E9ECBE1C5AF9D5C906023450675886BDECD`）

这一版动的是**地盘**：谁的地、谁管、在哪儿看得见。同时还破了项目从 v0.0.1 一直守到 v0.1.0 的一条红线。

## 新增 / 改动

**浮窗（本版最大的一块新东西）**
- 左上角一块面板，一行一个核心：`#1 [overworld] (100, 64, -200) 自己`。
- 显示**自己 + 队友的全部核心**——含未加载区块、含其它维度，按放置顺序（跨维度统一排序）。
- 9 个核心时显示 8 行 + 一行 `+1`（面板高 83 px / 93 px）。
- **H** 开关、**J** 进拖拽（单人世界会暂停），`ESC` 保存位置；`/farmstorm hud on|off|reset` 三个动作都写盘。
- 位置与开关落在新生成的 `config/farmstorm-client.toml`（3 键），与 server 配置分开。
- 数据面是**全项目第一个自定义网络包** `farmstorm:core_list`（S2C 只读，客户端不回包）。

**耕地-核心绑定制（把"范围内即受管"换成"显式绑定"）**
- 每块耕地只归 **1 个**核管理，**一个核最多管 16 块**（容量复用 `outpost_core.farmlandBonus`）。
- 锄地时绑给**最近**的己方核；平手按「放置更早 → 维度 id → 坐标字典序」三级。
- **修 bug ①**：一块耕地落在多个核范围内时，拆任意一个核就把地铲了 —— 现在只在没有接替核时才变泥土。
- **修 bug ②**：核主下线后他的田失去保护 —— 现在保护查绑定表，**离线照样生效**。
- 拆核时先迁移：改绑到「范围覆盖 + 同盟 + 还有空位」的最近核；迁不动才变泥土。
- 老存档启动时按新规则补建绑定（日志「耕地补建：绑定 N 块 / 保持未绑定 M 块」），**补不上的田保持耕地、绝不铲**。
- 额度改成 `farmlandBonus × 己方核数`，**删掉** `farmland.limitPerPlayer` 整组与 `/farmstorm farmlandlimit` 指令。
- 核所在区块做**运行期临时加载**（不写 `chunks.dat`，拆核/停服即释放）——没人的时候核也照常 tick。

**据点核心亮度**：`.lightLevel(state -> 15)`，放下就亮到 15。

**狂野苹果材质**
- 换成 **64×64** 原图直通（源图逐字节副本，6,946 B），不再降采样、不再走 16 网格众数取色。
- **「物品图标右下角叠绿色 +」这条规则自本版起全局作废**（机制已从生成器删除）。本版**只重生成狂野苹果 1 张**，其余 24 张仍带旧十字，留到下版批量处理。

**压缩干草块**：音效从草改成石头（破坏 / 放置 / 踩踏 / 挖掘 / 落地五类一起变）。

**man瓜（`farmstorm:pumpkin_turret`）**
- 开火间隔 60 → **40 刻**（2 秒）；伤害 1 → **3**；弹速 0.6 → **0.45**，并提成 config 键 `pumpkin_turret.bulletSpeed`（0.0 ~ 4.0）。
- 修**贴脸绕圈**：目标进到一个步长以内时按剩余距离收敛、进到 0.05 格内直接判中，并加防双结算闸。**没有**引入转向角上限之类的软追踪。

**朋友的韭**
- 从"落地闪一下"改成**落地后 `friend_chives.effectTicks` 刻（默认 200 = 10 秒）的持续场**：每刻重扫半径 6 格球体，施加 `effectTicks − x` 刻 Q弹。
- 落地后置零速度 + 无重力 + 免碰撞，实体在落点保持可见。
- 音效仍只在落地那一刻判一次：球内 ≥1 个生物播**一次**，空投不播。
- **区块卸载即结束**：不会在卸载/重载后留下永不消失的实体。

## 升级注意（0.1.0 → 0.1.1）

1. **`pumpkin_turret` 的两个默认值对已落盘的 toml 不生效**。要么删掉 `config/farmstorm-server.toml` 重新生成，要么手工把 `fireIntervalTicks` 改成 `40`、`projectileDamage` 改成 `3`。新增的 `bulletSpeed` 会**自动补成 0.45**。
2. **`/farmstorm farmlandlimit` 已删除**。额度现在跟着核心走：`outpost_core.farmlandBonus`（默认 16）× 己方核数。改这个键会**同时**改每核容量与队伍额度。
3. **老存档首次启动会补建耕地绑定**，控制台一条 INFO 带 N / M。补建只做绑定、**不改世界**；补不上的田仍是耕地，只是不受保护。
4. 背包/箱子里的物品与配方不变；不需要迁移存档。
5. 纯原版客户端（没装本模组）**仍可正常进服**——核心列表包走可选通道，服务端对未声明该通道的连接直接跳过下发。

## 已知限制

- **浮窗需要装本模组的客户端**。纯原版客户端看不到浮窗（服务端会跳过发包，不是报错）。
- **耕地坐标不带维度**：`farmland_farmland.dat` 的条目只有 `pos`、没有维度字段（0.1.0 起如此）。后果两条：下界 `(0,64,0)` 的耕地会被主世界同坐标的绑定"借"到踩踏保护；额度计数会把两维同坐标的地算成一块。**本版不修**（老档条目无法回溯维度）。
- **「拆核时找不到接替者且区块未加载 → 只摘绑定」这条降级分支在本版走不到**：核所在的 3×3 区块因临时加载常驻内存，而耕地范围正好也是这个 3×3。分支保留为防御性代码。
- **64×64 物品贴图的显示面积仍是 16 GUI px**，高出的细节会被平均——这是原版 `item/generated` 渲染的必然结果，不是破图。
- **重跑 `tools/gen_textures.py` 会把其余 24 张图标的绿十字剥掉**（「+」机制已删除），与「本版只重生成 1 张」冲突。**发布件不受影响**（jar 里是提交时的图），但不要在本版上重跑生成器。
- 上一版登记的「干耕地会毁苗」「边界粒子包量 48 包/圈」两条限制**依旧存在**，本版未动。
