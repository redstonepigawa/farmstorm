# 09 · Implementation vs Plan

> **Document status**: current for v0.0.1. This file compares the author's original text (`plan0.0.1.txt`) with what the code actually does. **The implementation baseline is `00-DECISIONS.md`** (D-42 ~ D-48 extend the D-01 ~ D-41 list); `01-DESIGN.md` and `02-TECH-SPEC.md` have already been aligned with the code, while `03-TASKS.md` ~ `06-PROMPT-TASKS.md` stay construction-period records and are not rewritten item by item.
> Scope: the 12 groups below are the complete set of differences between the plan and v0.0.1. Every row points at a decision (`D-xx` / `C-x` in `00-DECISIONS.md`) or at a ruling in `.work/PLAN.md` (`R-xx`); a row without such a basis would be a bug report, not a decision.

## 1. Difference list

| # | What the plan said | What the implementation does | Basis |
|---|---|---|---|
| 1 | A deployed block occupies the world with its own block texture (`textures/block/<id>.png`), visible like any other block | Trap deployments (`blast_carrot`, `fang_trap_cactus`) are **completely invisible in the world**: the block model carries no elements and keeps only a `particle` texture, while their item icons stay normal `item/generated` icons. Turret and aura deployments (`pumpkin_turret`, `awakened_torchflower`, `awakened_pitcher_plant`) use the **vanilla block models** pumpkin / torchflower / pitcher plant top | D-48 (appearance clause); PLAN R-38, R-40, R-41, R-44; DESIGN §3.3.6; TECH §6.3 |
| 2 | The one-shot trap settles on trigger; nothing forbids it from dropping its own block | The Blast Carrot **vanishes silently with no drop**, and its explosion **destroys no block, not even its own**. The block is removed before the explosion runs, so the loot table is never reached (previously it was reached through its own block being blown up) | D-46; PLAN R-52, R-53; DESIGN §4.2 |
| 3 | DEC §4 classified the Melon Slice Bomb as Damage only, so Demolition had 3 entries | The Melon Slice Bomb is **Damage + Demolition**: its explosion destroys blocks, with the threshold still "resistance ≥ cobblestone (6.0) is not destroyed". Demolition now has **4** entries: Ubi Server / Toxic Ubi Server / Melon Grenade / Melon Slice Bomb | D-42; PLAN R-48; DEC §4 row 6; DESIGN §2.3.3, §4.6 |
| 4 | The Pumpkin Turret locks onto non-friendly **players** within a Chebyshev distance of **5**, and the missile's damage has no stated owner | It locks onto non-friendly players **and hostile mobs** (`Monster`) within a Chebyshev distance of **15** (`pumpkin_turret.targetRadius`, range 0 ~ 64), and missile damage is **attributed to the placer** (empty attribution when the placer is offline) | D-43, D-44; PLAN R-47; DESIGN §4.8; TECH §4.6, §4.11.2 |
| 5 | Explosions follow vanilla `Explosion`, which exempts the source entity | Crop explosions **exclude no entity**: teammates, villagers and **the user themselves** all take damage inside the blast. Apart from `Entity#ignoreExplosion` there is no filtering at all — deliberately different from vanilla | D-45 (and D-27); PLAN R-54; TECH §4.9 |
| 6 | The converter is a **single input slot** that settles on take-out | The converter is **three slots + an explicit button**: Nether Star catalyst slot (Nether Stars only) / input slot / read-only preview slot, plus a "Convert" button that triggers settlement. Menu indices are 0 = input, 1 = catalyst, 2 = preview, player inventory from 3 (the visual left-to-right order is catalyst / input / preview). The catalyst is consumed from the slot first and falls back to scanning the player inventory | D-47 (supersedes DESIGN §3.1.2); PLAN R-26, R-45; TECH §4.8.2 ~ §4.8.4 |
| 7 | Traps and turrets target "non-friendly players" and say nothing about game mode | Traps and turrets additionally **skip creative-mode players** (spectators are skipped by the aura path as well), on top of the existing non-friendly-only rule | PLAN §14 (F-33 ③, backed by DoD-08); D-07 unchanged |
| 8 | "Turrets hard-mine for 10 seconds" was written as a category-wide rule | The fixed 10-second hard-mine applies **only to `pumpkin_turret`**. The Torchflower / Pitcher Plant are mined by the friendly side at vanilla speed, cannot be mined at all by non-friendly players and no explosion can destroy them | C-8, D-37 (a specific clause outranks a general one); DESIGN §2.3.2, §3.3.5 |
| 9 | Each crop has its own soil requirement (sand / grass block / low light, etc.), following its vanilla counterpart | v0.0.1 uniformly follows the vanilla `CropBlock` rule (**farmland only**). The per-crop soil differences are **not implemented** and are listed as a follow-up item; the design wording is kept | PLAN R-12; DESIGN §2.2.3, §3.2.2 (implementation-status lines) |
| 10 | Several numbers were missing from the plan or written loosely ("a few particles", radii not given) | The completion register is applied: fang rings **2.0 / 1.0** blocks, poison cloud **3.0 / 600 ticks**, projectile lifetime **100 ticks**, particles **8** per refresh, fire interval **60 ticks**, food values **4 / 0.3** with a 32-tick eat time | D-28 ~ D-31; DESIGN §3.8.6 |
| 11 | The resource inventory was counted as **257** files (JSON 169 + TOML 1 + PNG 87) and the language files as **216** keys | The real inventory is **261** files (JSON 169 + TOML 1 + PNG **91**; `textures/block` went 64 → **68**) and the language files hold **222** keys (`tooltip.farmstorm.*` = **16**: 9 base + 6 `.category.*` + 1 `.category_separator`, with the 3 `.type.<kind>` keys deleted) | TECH §6.1, §6.5, §7.1; PLAN R-28, R-29, R-49 |
| 12 | Vanilla textures were assumed to come from the 1.21.1 client | The vanilla crop textures were extracted from the **Minecraft 26.3 client** installed on this machine and overlaid; the version difference is registered in the delivery notes | PLAN R-04; DEC D-25 |

## 2. Maintenance rule

- A new deviation gets a row here **and** a `D-xx` / `C-x` entry in `00-DECISIONS.md` (or an `R-xx` ruling in `.work/PLAN.md`) in the same round. A number that changes in the code but not in `00-DECISIONS.md` is a defect, not a difference.
- `01-DESIGN.md` and `02-TECH-SPEC.md` carry the corrected wording; `03-TASKS.md` ~ `06-PROMPT-TASKS.md` keep the historical wording and only point back here.
