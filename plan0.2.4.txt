模组名：农场风云
版本号：0.2.4
使用neoforge模组加载器
minecraft本体版本：1.21.1
本版本以0.2.3版本为主，主要目标为修复目前已发现但还尚未修复的bug以及对部分物品进行数值调整，除非本文档明确要求，否则不能修改0.2.3原有内容
1.农作物转换器问题修复
{
	需要修复的问题：目前当一个绑定了据点核心的农作物转换器的据点核心被毁后，若其没有立刻绑定另一个据点核心，则其无法再被之后放下的据点核心绑定，本版本将所有带有farmstorm:processing_block标签的的方块与据点核心绑定的逻辑统一
}
2.村民交易问题修复
{
	需要修复的问题：目前所有本模组增加的交易项中，村民可获得的经验值都是一致的，修改所有的本模组新加的交易项，使其在不同阶段解锁的交易项获得的经验值不同
	（实装：1~5 级 = **2 / 5 / 10 / 15 / 30** 点；26 条 listing 逐项携带，农民 1/3/5 级 = 2/10/30）
}
3.核心浮窗修改
{
	为核心浮窗增加背景透明度，默认为30%
	（实装：`COLOR_BACKGROUND = 0x4D000000`，即 alpha **77/255 = 30.2%**；**硬编码在 `CoreHudRenderer`，不新增 config 键**（客户端配置仍 3 键）。边框仍是 `0xFF000000` 不透明）	
}
4.修复在农作物转换器和农作物培养器上放置方块时音效丢失问题
{
	需要修复的问题：目前当对一个农作物转换器或农作物培养器右键放置方块时音效会丢失
	（实装：三处都改了 —— 转换器、培养器，外加**据点核心**同一根因；做法是三处 `useWithoutItem` 的客户端分支改成「手持输入物才 `SUCCESS`，否则 `PASS`」，服务端四道闸一行未改）
}
