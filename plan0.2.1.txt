模组名：农场风云
版本号：0.2.1
使用neoforge模组加载器
minecraft本体版本：1.21.1
本版本以0.2.0版本为主，继续追加新的物品或功能，除非本文档明确要求，否则不能修改0.2.0原有内容
以下为追加内容
1.据点核心功能追加
{
	当一个据点核心绑定的农作物培养器数量小于16时，其每100刻会尝试绑定其影响范围内的未绑定的农作物培养器
		（实装：阈值现为 **24**（v0.2.2 起）；每 100 刻补绑的机制不变，v0.2.4 起补绑的候选范围扩到**所有**带 `farmstorm:processing_block` 标签的方块）
	打开据点核心的储物空间时把鼠标光标放在物品上时会显示物品详情（就像打开普通箱子时那样）
}
2.震动豆功能追加
{
	当非玩家生物被震动豆影响到时，其ai被删除4秒
}
3.Q弹效果追加
{
	当非玩家生物获得Q弹效果时，其ai被删除
}
4.陷阱类数值调整
{
	所有陷阱类作物对敌对生物的伤害变为原来的三倍
	（实装：只有 `blast_carrot`（胡罗贝）与 `zangief_cane`（桑吉尔蔗）参与，倍率键 `trap.damageMultiplier` 默认 3.0；`fang_trap_cactus` 走原版 `EvokerFangs`、`vibration_bean` 本来就是 0 伤害）
}
