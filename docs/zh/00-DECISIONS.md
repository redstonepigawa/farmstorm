### 玩法规则

| ID | 决策 |
|---|---|
| D-06 | 己方判定：v0.0.1 使用原版计分板队伍（Scoreboard Team）；同时抽出 `TeamResolver` 抽象接口，便于后续接 FTB Teams。 |
| D-07 | 触发对象：陷阱类与炮台类只针对**非己方玩家**，不处理生物。唯一例外：man瓜 保留对飞行中投掷物的拦截。 |
| D-08 | 改良作物全部配播种物品，与原版播种形态一一对应；收获时按原版比例同时掉落作物与播种物品，闭环自给。 |
| D-09 | 改良作物**不再具备原版用途**（不能做面包、不能喂动物、不参与原版配方）。 |
| D-10 | 「种植型」在 v0.0.1 不新增设计，只保留接口与规范；15 个作物因都有播种形态，天然可种植。 |
| D-11 | 转换器：单槽位 GUI + 数据驱动转换配方（自定义 RecipeType），双向可逆，1:1。 |
| D-12 | 转换成本：每次转换扣 **3 点经验值**（不足则拒绝转换，绝不扣等级）；火把花与瓶子草**仅「原版→激活版」方向**每次额外消耗 1 个下界之星，反向免费。 |
| D-13 | 部署物破坏：炮台类固定硬挖 **10 秒**；其他部署物正常挖掘速度。 |
| D-14 | 火把花 / 瓶子草：己方可正常挖取回收，任何爆炸都无法破坏；非己方玩家挖不动。 |
| D-15 | 火焰附加：给予期间的**临时附魔**，离开范围或到期自动移除，保留原有附魔不被覆盖。 |
| D-16 | 堆叠：投掷型 **16**，其余 **64**。投掷每掷出消耗 1 个。 |
| D-17 | 幸运浆果随机池：除自身外的其余 **14 种**（条目总数实为 15）。 |
| D-18 | 幸运浆果创造模式：记录原游戏模式，90 秒后强制还原；玩家中途下线则取消该效果，不写入存档。 |
| D-19 | 瓜片子与瓜！的爆炸抗性阈值统一为「无法摧毁爆炸抗性 ≥ 圆石（6.0）的方块」。 |
| D-20 | 距离度量：陷阱与炮台判定用**切比雪夫距离**；增益光环用**欧氏半径**。唯一例外：「赢过输过没死过」触发用**欧氏距离 ≤ 3**。 |
| D-21 | 所有数值原样照抄 `plan.txt`，v0.0.1 不做平衡调整；但必须进入 config 供服主调整。 |

| D-28 | man瓜 开火间隔 **60 刻（3 秒）**，进 config 可调。 |

| D-32 | 毒马铃薯在原版不可种植，故毒育碧服务器需**单独注册作物方块与播种物**，不与其他作物共用。 |
| D-33 | 幸运浆果生成物的落点偏移：取食用者**半径 2 格**内的随机可站立方块，放不下则就近。 |
| D-34 | 采纳 T-01：种植形态实现为 **14 个独立的 `FarmstormCropBlock`**（`<id>_crop` 等），不额外注册 BlockItem。 |
| D-35 | 采纳 T-02：部署型作物的物品是部署方块的 BlockItem，`useOn` 内分流「对耕地=播种 / 对方块=部署」。 |
| D-36 | 采纳 T-03：火把花/瓶子草的不可破坏由 `getDestroyProgress` 返回 0 + `playerWillDestroy` 二次校验实现，对创造模式同样生效。 |

| D-38 | 采纳 T-05：膨胀麦替换方块时跳过爆炸抗性 ≥ 3600000 的方块（基岩/屏障等）。属防破坏底线，不算平衡调整。 |
| D-39 | 采纳 T-06：自定义伤害类型 2 个——`farmstorm:void_bolt`（炮台导弹）、`farmstorm:crop_blast`（作物爆炸）。 |
| D-40 | 采纳 T-07：**不引入 Mixin**。全部需求用继承 + NeoForge 事件总线 + 原生扩展点完成。 |
| D-41 | 采纳 T-08：临时附魔用 DataComponent `farmstorm:temporary_enchantments` 记录在**物品上**，不用玩家持久数据。 |

## 5. 对 plan.txt 原文的修正

| ID | 修正内容 | 理由 |
|---|---|---|
| C-1 | 条目总数为 **15**，不是 16。幸运浆果随机池因此为 14 种。 | 逐条核对 plan.txt 第 33~156 行。 |
| C-2 | 瓜片子「无法摧毁爆炸抗性 ≥ -1 的方块」改为「≥ 圆石（6.0）」。 | 作者确认为笔误，与瓜！对齐。 |
| C-3 | man瓜 保留拦截投掷物；其余炮台只锁定玩家。 | 作者确认，收窄适用范围。 |
| C-4 | 火把花 / 瓶子草在 plan 中被归为「炮台类」，但没有攻击行为。保留分类标签，技术上按「光环提供者（AuraProvider）」实现。 | 分类是给玩家看的，实现按行为走。 |
| C-5 | 「赢过输过没死过」触发距离用欧氏距离 ≤ 3。 | plan 未指明度量，作者确认取欧氏。 |
| C-6 | 粒子与音效广播**使用原版包**（`ClientboundLevelParticlesPacket` / `ClientboundSoundPacket`），不引入任何自定义 S2C 网络包。 | 跨文档矛盾：DESIGN §3.5 / §7.16 与 TECH §5.5 冲突，以 TECH 为准。自定义包只会增加同步面与版本脆弱性。 |
| C-7 | 进度（advancement）数量为 **12 条**，对应 12 个 `data/farmstorm/advancement/*.json` 与 24 个 lang 键。 | 跨文档矛盾：DESIGN §6 列 12 条，TECH §6.1 只计 6 个，以 DESIGN 的 12 条为准。 |
| C-8 | 火把花 / 瓶子草被己方玩家挖掘时用**原版正常挖掘速度**；D-13 的「固定硬挖 10 秒」**只适用于 `pumpkin_turret`**。 | 跨文档矛盾：DESIGN §3.3/§4.9/§4.10/§7.1 把它们也写成 10 秒，与 D-14 原文「己方可挖取回收（正常挖掘速度）」冲突。D-14 是访谈原话，优先级最高；D-37 已明确收窄 D-13。 |
| C-9 | 部署方块**只存 `ownerUuid` + `ownerName`，不存队伍快照**；己方判定在触发瞬间实时解析归属者的当前队伍；归属者离线时按其最后已知队伍在 Scoreboard 成员表反查。 | 跨文档矛盾：DESIGN §7.2 与 TECH §4.2/§4.5 冲突。取 DESIGN 口径：可少一个同步字段，且队伍变更即时生效。归属者无队伍时按 D-31 的 `self` 口径。 |
| C-10 | 英文显示名的唯一规则：**显示名 = 注册 ID 的 Title Case**。15 个作物的英文名定为 Puffed Wheat / Blast Carrot / Ubi Server / Toxic Ubi Server / Power Beet / Melon Slice Bomb / Melon Grenade / Pumpkin Turret / Awakened Torchflower / Awakened Pitcher Plant / Fang Trap Cactus / Bamboo Firecracker / Red Mushroom Puff / Brown Mushroom Puff / Lucky Berry。 | 四路并行翻译各自造名，产出 `Ubisoft Server`/`Ubi Server`、`Beet!`/`Power Beet`、`Melon!`/`Melon Grenade`、`Man Melon`/`Pumpkin Turret` 等分歧。绑定到注册 ID 后不再有解释空间。 |
