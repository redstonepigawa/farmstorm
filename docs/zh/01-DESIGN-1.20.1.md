## 4. 已知影响（4 条，都要写进 README 与签字）

1. **老存档不兼容**：1.21.1 世界在 1.20.1 版打不开（方块/组件 id 与 `data_component_type` 都不存在）。不是缺陷，是既定代价（D-014）。
2. **两端不能混装**：协议串 `"1"` 与 1.21.1 的 `"3"` 互斥；1.21.1 客户端连 1.20.1 服务端（或反之）拿不到连线/浮窗通道，不崩但看不到（D-008）。
3. **临时附魔的实现换了**：物品上的数据从「组件」变成**物品 NBT**（`FarmstormTempEnchants`；实体侧 `ai_suspend` 走实体持久 NBT `FarmstormAiSuspend`，不走 Capability）。玩家观感一致，但**跨版本搬运物品无法保留**该状态（D-009）。
4. **资源包格式跳变**：`pack_format 34 → 15`；材质文件本身不变，但自定义资源包需要按 1.20.1 打包（D-014）。

## 6. 不做的事

- 不做存档迁移工具（D-014）。
- 不做「双版本共用一个 jar」的 multi-release 打包。
- 不为了兼容 1.20.1 而改动 1.21.1 主线的任何源码或文档。
- 不新增玩法特性；本移植的验收基线是「与 v0.2.4 一致」。
