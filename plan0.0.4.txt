模组名：农场风云
版本号：0.0.4
使用neoforge模组加载器
minecraft本体版本：1.21.1
本版本以0.0.3版本为主，继续追加新的物品或功能，除非本文档明确要求，否则不能修改0.0.3原有内容
以下为修改内容（本版不新增任何物品、方块、状态效果、进度或 config 键）
1.朋友的韭 命中音缩短为 10 秒
{
	原因：0.0.3 用的是整首曲子（158 秒）没截断，一投出去就一直在响
	要求：从开头取 10 秒，规格保持 mono / 48 kHz / 64 kbps
	实现补充：截取在 ffmpeg 输出侧单趟完成（不放临时文件、不二次编码）；音频分支统一加 -fflags +bitexact，使 ogg 可复现 —— 同一源三次重建字节完全相同
}
2.修复：看不见其它拥有 Q弹 状态的玩家的模型变化
{
	现象：只有自己带 Q弹 时才看得到模型在动；别的玩家带效果时，他身上什么都不动
	根因（两层）：
		① 姿态参数取自「本机玩家」的时钟，别的实体的相位恒为 0（旋转 0 度、压缩 1.0）
		② 原版只把「实体获得了什么效果」发给这个实体自己的连接，观察者客户端根本不知道别人身上有 Q弹
	修法：
		① 相位改成按实体各自计时（客户端维护一张内存表，实体不再带效果就清理）
		② 服务端每 20 刻向半径 64 格内的观察者补发一次原版效果包；效果到期 / 被清除 / 实体死亡三条路径立刻补发移除包
	红线：仍然不用自定义网络包（CustomPacketPayload 保持 0），用的是原版效果包（与 0.0.2 的循环音复用原版声音包同一口径）
	已知代价：① 走出 64 格就看不到（走回来 1 秒内恢复）；② 观察者客户端的 activeEffects 里会看到别人身上的 q_bounce，第三方实体提示类 GUI（Jade / WAILA 之类）会把它列出来
}
3.Q弹 的控制力降低：只锁移动
{
	原因：0.0.3 的 Q弹 与桑吉尔蔗 共用同一套七段全锁（移动+跳跃+潜行 / 鼠标按键 / 攻击与使用 / 键盘 / 滚轮 / 视角灵敏度 / GUI），手感太重
	要求：Q弹 只锁 WASD 移动 + 跳跃 + 潜行；鼠标、攻击与使用、滚轮、视角、背包全部放开
	不变：桑吉尔蔗 仍保持七段全锁
	实现补充：混乱的「锁优先」跟着改成判「移动锁」—— 混乱反转的正是移动分量，与 Q弹 锁的是同一处
}
4.Q弹 期间强制第三人称
{
	要求：进效果时记下当前视角 → 效果期间每刻强制第三人称（按 F5 会被拉回）→ 效果结束 / 被清除 / 死亡 / 退出世界时恢复记下的那个视角
	实现补充：固定用「第三人称·背后」，不沿用玩家原来选的前/后 —— F5 是三档循环，固定一档才不会出现「按一下到第一人称、下一刻又被拉走」的两跳
	不变：桑吉尔蔗 的相机倒转不动（那是 ViewportEvent 的 roll/pitch/yaw 改写，与「第几人称」是两个不相干的量）
}
补充：关键数字与 0.0.3 相同 —— 注册对象 90、config 键 155、语言键 299×2、改良作物 22、进度 18；红线条数不变（无自定义网络包、无 Mixin）。
补充：本版仍未在真机验证的观感项 —— Q弹 的坐姿外观、桑吉尔蔗七段锁的手感、以及本版新增的强制第三人称（开发环境的图形客户端起不来）。
