# Farmstorm 农场风云 v0.2.0

> Minecraft 1.21.1 · NeoForge 21.1.213 · Java 21 · modid `farmstorm`
> 下载：`farmstorm-0.2.0+mc1.21.1.jar`（1,119,199 字节 / SHA256 `9B87AEFC5E6A60FF56D513C96E6E59F496DE8270F7C02015FA8801B22E75CB8A`）
> 源码包：`farmstorm-0.2.0+mc1.21.1-sources.jar`（1,041,068 字节 / SHA256 `222B4734C41F0CB9C7A4A7A130C4F46BB098FB577A31602956B575C86A3C4B29`）

这一版第一次**推翻自己上一版的核心机制**：0.1.1 的耕地-核心绑定制整体停用，那个「16」换了所指——从「每核多少块耕地」变成「每核多少个培养器」。

## 新增 / 改动

**据点核心变成 54 格容器**
- 己方空手右键打开（6 行 × 9 列 + 玩家背包），标题「据点核心」；非己方打不开。
- 距离闸走原版 `stillValid`，界面开着走远会被自动关掉。
- 挖掉时**整箱内容一起掉**；活塞推动 / 同方块替换 / 区块卸载这三种「非真移除」不掉（防复制）。

**培养器 `farmstorm:cultivator`（新方块）**
- 放下时自动绑给**最近**的己方核（核所在 3×3 区块内），一个核最多 **16** 个。
- 四道闸：范围 / 绑定 / 手持品质（**史诗拒绝**）/ 空槽，任一不过 = 右键无反应。
- 每 **600 刻**（30 秒）把产出投进绑定的核：**普通与稀有**投 2 个作物；有独立种子的再加 2 个种子（准入面内 5 条给 2+2、13 条只给 2）。
- 核满了就停在 `cycleTicks`、物品不丢；腾出格子后自动投递，**不重新计时**。
- 没有槽位界面（右键直接放入/取出）；挖掉时掉自身 + 内部那一个。
- 双态模型 + `.png.mcmeta` 帧动画（本版第一个动画贴图）。

**农民交易：史诗档的唯一入口**
- 农民在第 **1 / 3 / 5** 级各多一项本模组交易，只收绿宝石，每项 `maxUses = 1`。
- 价格 普通 2–5 / 稀有 10–32 / 史诗 40–64；单次给 2 个同档作物；报价在生成时抽一次，**成交时不重掷**。

**连线**
- 站在自家核的 3×3 区块内，能看到核与每个已绑定培养器之间的青蓝色线（两端各一个 0.25 格小框）。
- 走远线消失、换维度不残留、拆方块线立刻消失。**纯观察面**：关掉不影响绑定 / 产出 / 迁移 / 掉落。

**品质**
- 22 条作物档案各有一档：普通 **11** / 稀有 **7** / 史诗 **4**，是交易抽样、培养器准入、幸运浆果池三处的唯一数据源。
- 29 个物品名按档着色（普通白 / 稀有蓝 / 史诗金），tooltip 多一行「品质：稀有」。**贴图一张没改**。
- 幸运浆果池从 19 收到 **11**（只滚普通档）。

**撤销的东西（「注释 ≠ 删除」）**
- 耕地绑定制**只注释调用点**：不再拦锄地、不再有踩踏保护、两条动作栏提示不再出现。
- `FarmlandLedger` / `FarmlandGuard` 两个类（555 / 225 行）**保留在源码树里、仍编译**，只是没有运行期调用者；`farmstorm_farmland.dat` **不读不写不删**。
- 作物与种子**不能再种**（15 个作物物品 + 7 个种子右键耕地无反应、不消耗；7 个部署型物品照常摆出）。
- 农产转换器只作装饰：右键无反应，但方块、29 条配方、创造栏条目全部保留。

## 升级注意（0.1.1 → 0.2.0）

1. **config 组结构变了**：`farmland` 组消失；新增 `[trade]` 6 键与 `[cultivator]` 2 键；`[outpost_core]` 从 3 键变 4 键（删 `farmlandBonus`，加 `cultivatorCapacity` / `storageSlots`）。**建议删掉 `config/farmstorm-server.toml` 重新起服**（会重生成 175 键 / 60 组）；不删也能跑，但旧键会残留。
2. **作物不能种了**：手里的作物 / 种子右键耕地没反应（不消耗）。这是本版设计。
3. **老档的核心**读成 54 个空槽，主人与放置时间保留。
4. **老档的满级农民不会补发**那 3 个交易项（本版不做迁移，新刷的村民才有）。
5. **老档的 `farmstorm_farmland.dat`** 原样留在存档里，本版不再读写、也不会删。
6. 物品、配方、进度都向后兼容，不需要迁移存档。

## 已知限制

- **培养器必须在核的 3×3 区块内才可用**。核被拆后会迁移；迁不动的培养器留原地但**永久未绑定、不可使用**（只能拆掉重放）。先放培养器、后放核也不会自动认领。
- **史诗作物无法进入培养器** —— 史诗档只能靠农民交易拿。
- 培养器**没有槽位界面**（右键直接放入/取出）。
- **连线与浮窗需要装本模组的客户端**；纯原版客户端仍能正常进服，只是看不到它们。
- **连线的视觉观感未经人眼验收**：服务端发包、客户端收包、10 分钟不崩都有实测，但线框颜色与观感需要玩家确认。
- 耕地坐标不带维度（`farmstorm_farmland.dat` 只有 `pos`）——本版已停用该文件，不再影响玩法。
- 历史遗留（0.0.2 起就有，本版未动）：世界灰度不含 HUD；桑吉尔蔗「视角锁定」只是降速约 15.6 倍；F11 / F2 / F3 / ESC 拦不住；1×1 石柱构型落地约 23 刻；狂野猎人期间亮度滑条显示为满；火把花光环离开后火焰附加最多再留 15 秒；干耕地会毁苗；据点核心边界粒子每圈 48 个包。
