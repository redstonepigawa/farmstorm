1.本模组农作物特性修改
{	
	对本模组农作物进行品质分级，分别为普通，稀有，史诗
		普通品质：膨胀麦，胡罗贝，man瓜，瓜！，瓜片子，？！菇菇！？，？！棕色菇菇色棕！？，莫洛托夫，刺球，爆竹，震动豆以及以上作物的种子（如果有）
		稀有品质：桑吉尔蔗，朋友的韭，甜菜！，压缩膨胀麦以及以上作物的种子（如果有）
		史诗品质：幸运浆果，激活的火把花，激活的瓶子草，狂野苹果以及以上作物的种子（如果有）
	本模组所有农作物不再被允许在耕地上被种植
	拥有农民职业的村民在每个等级阶段都会额外解锁一个使用绿宝石交换本模组农作物的交易，普通品质作物每次交易消耗2-5个绿宝石，稀有品质消耗10-32个绿宝石，史诗品质消耗40-64个绿宝石，并且每次只能交易一次
	幸运浆果不再产出稀有品质和史诗品质的农作物
}
2.新增方块
{
	方块名：农作物培养器
	方块硬度和爆炸抗性参考铁砧
	功能：当且仅当该方块处在一个己方据点核心影响范围内并且被一个己方据点核心绑定时可使用，手持本模组的普通或稀有品质农作物或者其种子右键可将其放入该方块中培养，一次只能放入一个，三十秒后产出2个对应农作物以及2个种子并自动存放在其绑定的据点核心的存储空间中，当其处于工作状态时播放预设好的翻书动画
	材质："C:\Users\DASHpig\Downloads\cultivator_a_animation_pack"
}
3.据点核心方块大型重做
{
	1.撤销一切本模组有关耕地的改动，玩家现在的耕地数量不再受到数量和位置限制
	2.据点核心不再绑定耕地，现在据点核心拥有一个容量为16的列表，用于储存与其绑定的农作物培养器的信息，当一个核心被拆时，与其绑定的农作物培养器会寻找可以与其绑定的其它己方据点核心，否则该农作物培养器无法使用
	3.右键据点核心时会打开其内置的存储空间（相当于一个大箱子）
	4.当玩家处在己方据点核心影响范围内时，与该据点核心绑定的农作物培养器会与据点核心产生一条可见的连线（无实体，不对任何方块和实体影响，仅指示位置）
	5.当据点核心被破坏时，其存储的所有物品会掉落
}
