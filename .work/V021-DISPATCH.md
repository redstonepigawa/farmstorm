## 3. 每个子代理统一的硬约束

1. 构建只走 `.tools\gw.cmd`，禁止直接调 gradle。
2. **禁止任何 git 写操作**；只许 `git status` / `git diff` / `git log` 取证。提交由调度者做。
3. **禁止改 `docs/`**（40~45 与更早全部冻结）、`build.gradle`、`.tools/`、`run/`（计划内 toml 重生成除外）。
4. 每条判据**改前先跑一遍记下实测值**（陷阱 20 式的元规则），改后再跑一次。
5. 渲染 / 听感 / 需第二客户端 → 标「未验证」+ 代码层证据，**不许编读数**。
6. 一个任务一组文件；回报按任务分段，便于调度者按任务提交。
7. 拿不准的写进「未决问题」，不许自己定新数值。
8. **toml 读数只认 `run/config/farmstorm-server.toml`**，且取数前先跑一次 `runServer` 重生成（45 号 §0.2 ③）。

## 4. 调度者的复核动作（每个 Phase 后）

1. 读 `git status` / `git diff --stat`，确认改动面只落在本 Phase 任务清单内。
2. 亲自跑闸门命令（build / jar 版本行 / grep / 计数 / 起服读日志），不采信自述。
3. 通过则按任务分段提交；不通过则带证据重派，同一任务书最多重派两次。
