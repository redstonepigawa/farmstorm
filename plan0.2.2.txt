模组名：农场风云
版本号：0.2.2
使用neoforge模组加载器
minecraft本体版本：1.21.1
本版本以0.2.1版本为主，继续追加新的物品或功能，除非本文档明确要求，否则不能修改0.2.1原有内容
以下为追加的内容
1.新增村民职业
{
	职业名：植物学家
	职业方块：据点核心
	交易内容：本模组所有的农作物对应的原版农作物或本模组的平凡农作物，定价统一为3-6绿宝石，交易次数限制为8次，此外会额外刷新出一个史诗品质改良农作物交易，可交易一次，价格为40-64绿宝石
	（实装：22 项普通交易摊在 **1~4 级 = 6/6/6/4**；原版村民每级只从事表里抽 2 项 ⇒ 一个植物学家满级最多只看到 **8 项**，凑齐 22 项要多找几个。史诗 1 项在 5 级大师，40-64 绿宝石、只能换一次。v0.2.4 起成交经验按级分 2/5/10/15/30）
	
}
2.新增物品类型：平凡农作物
{
	目的：用于解决本模组中部分改良农作物没有对应原版农作物的问题，平凡农作物和改良农作物相比更贴近于原版农作物，以后每增加一种新的没有对应原版农作物的改良农作物时，必须同时增加一种与其对应的平凡农作物
	
}

3.新增物品标签
{
	标签名：farmstorm:processing_block（实装 ID：冒号分隔）
	功能：带有该标签的方块可以被据点核心绑定
	
}
4.农作物培养器新增标签farmstorm:processing_block（实装 ID：冒号分隔）
5.据点核心问题修复与数值调整
{
	修复在据点核心储物空间界面中背包物品显示位置略微上移导致与格子对不上的问题
	修复在据点核心储物空间界面没有tooltip的问题
	据点核心的放置数量上限改为4
	单个据点核心可绑定24个带有farmstorm:processing_block标签的方块（实装 ID：冒号分隔；这 24 个名额由**所有**带该标签的方块共享）
}
