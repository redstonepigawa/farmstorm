# 09 · 实现与计划差异对照（Impl vs Plan）

> 基准：`plan0.0.1.txt`（作者原始设想）+ `docs/zh/00-DECISIONS.md`（唯一真相源）。
> 本文件只登记**已经落地的差异**：左侧是原计划/施工期文档写的，中间是 `src/` 里真实的实现，右侧能指到 DEC 的 D/C 编号或 `.work/PLAN.md` 的 R 编号。
> 读法：要判定「哪边算数」一律看右侧依据；没有依据的差异说明还没裁决，应当上报而不是照抄任一侧。
> 相关：`03-TASKS.md` ~ `06-PROMPT-TASKS.md` 是施工期历史记录，顶部已标注「实现口径以 00-DECISIONS.md 为准」（DOC-22）。

## 1. 差异清单（12 组）

| 原计划写的 | 实现是什么 | 依据 |
|---|---|---|
| 5 个部署方块都用方块贴图外观（`textures/block/<id>.png` 直接贴上去） | **陷阱类**（胡罗贝、赢过输过没死过）在世界中**完全隐形**：空模型（无 elements），只保留 `textures.particle`；物品图标独立走 `item/generated`，不跟着隐形。**炮台类与光环类**（man瓜、激活的火把花、激活的瓶子草）改用**原版方块模型**（`minecraft:block/pumpkin` / 火把花 / 瓶子草），并靠 `DeployedCropBlock#getRenderShape() → RenderShape.MODEL` 让模型真的渲染（父类默认 `INVISIBLE`） | D-48；R-38、R-40、R-41、R-44、R-43 |
| 一次性陷阱触发后照常掉落本体（方块照常走战利品表） | 胡罗贝被触发后**静默消失、不产生掉落物**；它的爆炸**不破坏任何方块**（含自身）——它没有破障类标签，`BlastRule.forCrop` 直接返回 `NEVER_BREAK` | D-46、D-48；R-48 |
| 瓜片子只是**伤害类**（DEC §4 原文与 `plan0.0.1.txt` 均如此） | 瓜片子的类别是 **伤害类、破障类**：其爆炸可破坏方块，阈值仍为「爆炸抗性 ≥ 圆石（6.0）不破」（与瓜！同阈值）。破障类因此从 3 种变为 **4 种**：育碧服务器 / 毒育碧服务器 / 瓜！ / 瓜片子 | D-42、D-19、C-2；R-48 |
| man瓜 索敌切比雪夫 **5** 格，只打**非己方玩家**，导弹没有归属说明 | 半径 **15**（`farmstorm.pumpkin_turret.targetRadius`，0 ~ 64 可配）；目标是**非己方玩家 + 敌对生物**（原版 `Monster`）里最近的一个，两者平手判给玩家，仍无目标时才回退投掷物拦截；导弹命中的伤害**归属放置者**，放置者离线则归属为空 | D-43、D-44；R-47 |

## 2. 便于引用的两条口径

1. **判定谁是唯一真相源**：玩法与结构口径以 `00-DECISIONS.md` 为准（D-42 ~ D-48 是本轮新增）；`01-DESIGN.md`、`02-TECH-SPEC.md` 已按 D-42 ~ D-48 同步修订。
2. **计数自查方法**：`textures/block/*.png` 用文件计数；语言键用 `src/generated/resources/assets/farmstorm/lang/en_us.json` 的键数（中英键集必须完全一致）。启动自检会打印 `自检 作物 15 种：投掷型 8 / 部署型 5 / 食用型 2；破障类 4 → OK`，数字一变就说明 DEC §4 那张表被动过（R-51）。
