## 0. 你面对的是什么

v0.2.1 是**小增量**：`plan0.2.1.txt` 的 4 条追加（落在 `:9` / `:10` / `:14` / `:18` / `:22` 五个行号上，第 1 条占 `:9` 与 `:10` 两行）拆成 5 条需求 R1 ~ R5（41 §1），注册对象 **+0**、config **+1 键**、语言键 **+1**。它不像 0.2.0 那样整块换机制，**但有两处「全项目第一次」、一处「推翻上一版自己的承诺」**——三处都不是「照着抄一个类」能过的。

第三条是最容易读歪的一处：**「局部取代」不是「整条推翻」**。D-165 的选核判据、**16 上限**、一对一不变量、**「绑定的唯一真相在核侧」**全部保留（40 §5 读表要点）。把「补绑」读成「改用培养器侧缓存当真相」，等于把上一版的骨架一起拆了。

**三条最贵的读法**（背下来，它们决定了本版一半的返工）：

1. **100 刻不是「接上去就有」**：`serverTick` 现有粒子相位门在 `:516-518` 就 `return`。补绑若接在它下游，实际周期 = `LCM(40, 100) = 200` 刻，且随 `boundaryParticleIntervalTicks`（默认 40、可配 20 ~ 1200）漂移 ——「每 100 刻」当场失效（42 §2.1.1）。
2. **4 个陷阱作物里只有 2 个参与 ×3**：plan 原文是「**所有**陷阱类作物」，裁定 #11 收窄为 `blast_carrot` 与 `zangief_cane`；`fang_trap_cactus`（伤害在原版 `EvokerFangs` 里、仓内 0 处 `hurt`）与 `vibration_bean`（0 伤害）**不参与**。写「所有陷阱 ×3」即错，验收会跟着错（RT-58、41 §6.4）。
3. **97 里没有那个附件**：`farmstorm:ai_suspend` 注在 `NeoForgeRegistries.Keys.ATTACHMENT_TYPES`，是**本项目 12 类口径外的第 13 类**；97 不变，但**必须显式登记**——工具对它既不核存在也不核计数（裁定 #17、42 §1.2.1）。

**五条需求都不长在注册面上**：补绑用既有的 `OutpostCoreBlockEntity` + `CultivatorBlockEntity`；tooltip 走原版 `AbstractContainerScreen` 链路；区域枚举与敌对谓词都是纯静态工具类；AI 原值走**口径外**的实体附件；倍率是 config 键 ⇒ 97 不变、网络包仍 2、Mixin 仍 0（42 §1.2 表下的注）。四个「加了但不进注册面」的构件逐个点名：`util/AreaBlockEntities`、`util/Hostility`、`combat/MobAiSuspension`（含 `Suspend`）、`trap.damageMultiplier`——**别按「新增类数」推断注册面**，那会得出 101 的错误结论。

任务、Phase、里程碑与工时全部在 43 号（F-247 起 / Phase 40 起 / M36 起 / A-70 起），本文只引它们的编号，**不复述排期**。

## 7. 回报格式

每份回报固定四段，**顺序不变、缺段即未完成**：

```
## 结论
一句话：做了什么、对应哪几个编号（F 号 / D 号 / 45 号的任务小节 / 42 §3 的动作面行号 /
42 §7 的验收号 / 41 §9 的 B 号）。禁止写「完成」「正常」「没问题」——那不是结论。

## 证据
每条判据三行：命令原文 → 关键输出（原样一至三行）→ 编号（HC-xx / N-xx / 42 §7 #n / 41 §9 B-nn）。
计数类判据给「改前实测值 / 改后实测值」两个数（陷阱 20）。
改动面给 `git diff --stat` 的文件清单（一任务一提交，多一个文件就是超范围）。
存档类判据给 `/data get block|entity <pos|mob>` 的键摘录，或停服后的文件读数。

## 未决问题
拿不准的、文档之间冲突的、需要作者拍板的。没有就写「无」——不许省略这一段。

## 下一步
按 43 号的依赖图，下一个该做的任务号；以及本轮**没做**但已经看见的问题（只登记，不动手）。
```

三条约束：

1. **证据必须是可观察的**：日志行、命令读数、`git diff`、`jar tf`、存档 NBT、游戏内读数。日志超过 20 行只留**第一条错误**与**总结行**。
2. **每条断言都要落编号**：没有编号的断言按「未验证」处理；写了编号但没给读数的，按「未跑」处理。
3. **不许只贴文件内容**：`git diff` 只贴改动的那几行，不贴整文件；日志只贴命中行。回报是给下一个人做判断用的，不是存档。
